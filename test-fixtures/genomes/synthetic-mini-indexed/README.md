# synthetic-mini-indexed (DNA-G1)

Deterministic 50 kb synthetic GenBank fixture. Used by the sidecar indexer's L0
byte-exact reproducibility tests against `samtools faidx` and `tabix -p gff`.

## Provenance

Synthetic, deterministic. Generated by `generate.py` with seed `20260504` using
BioPython 1.80+. Contains five gene/CDS pairs at fixed coordinates.

```
gene  start    end    strand
A     1000     4000   +
B     8000    11000   -
C    15500    18200   +
D    25000    28000   -
E    40000    44500   +
```

## Regenerate

```bash
cd apps/api
uv run python ../../test-fixtures/genomes/synthetic-mini-indexed/generate.py
```

The committed `source.gbff` is the source of truth for tests.
