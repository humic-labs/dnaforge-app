# Native chromosome contacts

U00096.2.fasta is the exact U00096.2 reference, 4,639,675 bases.
GSM2870426.contacts.json retains all 2,209 measured cells of the 47 × 47
100 kb aggregate of the public GSM2870426 chromosome-contact matrix. Each
count is the exact sum of the corresponding 5 kb source cells; the last
interval ends at the true reference length. Counts are not normalized.
