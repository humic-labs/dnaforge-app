# Restart restoration

## Sub-features

- Restore registered active roots after a process restart.
- Restore a valid current preference.
- Keep archived, trashed and unavailable roots out of the restored collection.

## How to get to it (user POV)

Quit DNAForge and reopen it. The Files collection is restored from native
project registration. A temporary hide in the running session is not a permanent
dismissal policy.

## Driving it with Playwright

After the transitions phase, stop and restart the same owned preview. Run the
restored phase against its existing evidence directory. Assert native
registration, displayed roots and the current preference together; retain
original video and action receipts.

## Gotchas

Use the same profile and ports. A fresh temporary profile cannot prove restart
persistence. Do not turn the last-project refusal into an empty-session feature
or introduce permanent dismissal during an ownership refactor.
