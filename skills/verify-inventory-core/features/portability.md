## Independent states

An export retains one captured artifact through destination cancellation,
writing, readback confirmation, saved output and unknown output. A later source
revision requires a separate capture. A write acknowledgement is not saved-byte
proof.

An import pins exact source bytes, scientific mappings and an observed target.
Its preview is blocked, ready, no-change or stale. Applying retains one stable
operation identity through committed, refused and outcome-unknown recovery.
Discarding a draft cancels intent without changing inventory. Preview does not
create a database row, receipt, journal entry, event, source copy or review
file.

## Natural workflow

Export a native inventory with complete history beyond one public history page.
Preserve exact stored state, request and receipt strings with content hashes.
Include scientific dependencies while keeping their documents under their
existing owner. Preserve exact codes, retired/withdrawn evidence, quantities,
concentrations, plate wells, stack order, custody, holds, physical pins and
thermal relationships. Never turn unknown into zero or a former location into a
current location.

Preview into an absent admitted destination with explicit scientific bindings.
Read-only authority can export and preview; applying needs present write
authority. Revalidate the source, target revision, dependencies, plan digest,
owner and grant at acceptance. Source actors and timestamps are recorded
attribution, never destination execution authority. A matching destination agent
ID cannot own an imported reservation or custody responsibility.

Adopt once through the existing atomic native inventory journal. Destination
revision starts at one under the importer's native receipt; original source
history remains labeled source evidence. Lose the acknowledgement, restart, and
recover the original receipt. Changed bytes under the same operation ID
conflict; a duplicate adoption under a new ID refuses against populated state.

Re-export and check both guarantees separately: retained source strings remain
byte-identical, and destination facts equal the explicit transformed plan. Only
declared scientific bindings, imported-attribution wrappers, destination
revision and native recorded clock may differ. Imported qualification retains
its original scope and does not become a new physical qualification.

## Negative boundaries

Reject duplicate JSON keys, tampered payload hashes, incomplete history,
request/receipt/digest mismatch, duplicate identities, unresolved scientific
bindings, occupied targets, future source recorded clocks and unsupported source
versions. Preserve the complete refusal and prove zero effects.

Measure encoded transport limits and refuse oversize input explicitly. Do not
silently chunk or create a second journal. Preserve original screenshots, video,
source files, failed attempts and exact native/file readbacks outside the
checkout.
