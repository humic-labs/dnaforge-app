# Inventory core feature map

- [Native inventory commands](native-inventory.md): physical stock, placement,
  exact quantity, atomic command outcome, history and recovery.
- [Inventory workspace](inventory-workspace.md): project selection, hierarchical
  locations, receive, move, use, history and application reopen.

- [Lots and material operations](material-operations.md): batches, aliquots,
  pooling, tracked dilution, container limits and restart parity.

- [Plates, tube boxes and stacks](layouts.md): permanent wells, aggregate moves
  and disposal, ordered retrieval and refusal.

- [Composition and concentrations](concentration.md): exact ratios, explicit
  unknowns, lossless edits and immutable input facts.

- [Reservations](reservations.md): explicit holds, available quantity, partial
  fulfillment, stable holders and recorded release or expiry.

- [Physical custody](custody.md): empty containers, aggregate checkout, return,
  missing observations, transit and immutable location history.

- [Physical configuration](physical-configuration.md): reusable types, pinned
  recipes, scoped fit evidence and source-backed installed arrangements.

- [Catalog lifecycle](catalog-lifecycle.md): explicit retirement, selected
  component eligibility, source-pack previews and controlled publication.

- [Physical item codes](item-codes.md): scoped exact lookup, immutable bindings,
  retirement, ambiguity and separate expected-item checking.

- [Existing-code labels](labels.md): bounded QR rendering, exact SVG export and
  independent decoding of the actual saved artifact.

- [Storage conditions](storage-conditions.md): exact temperature facts,
  formulation requirements, source scope and independent assessments.

- [Archives and adoption](portability.md): exact source evidence, zero-write
  preview, explicit scientific bindings and durable import recovery.

- [Receive tables](receive-tables.md): stable source rows, explicit destination
  decisions, atomic stock receiving and duplicate prevention.

- [Stocktake observations](stocktake.md): recorded measurements, independent
  correction decisions, missing/found custody and preserved holds.

- [Source revisions](source-revisions.md): append-only acceptance of revised
  external records, separate from current physical inventory.

- [Hierarchy tables](hierarchy-tables.md): explicit storage layouts and parent
  references, stable physical identities and atomic tree import.
