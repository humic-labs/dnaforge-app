# Inventory core feature map

- [Native inventory commands](native-inventory.md): physical stock, placement,
  exact quantity, atomic command outcome, history and recovery.
- [Inventory workspace](inventory-workspace.md): project selection, hierarchical
  locations, receive, move, use, history and application reopen.

- [Lots and material operations](material-operations.md): batches, aliquots,
  pooling, tracked dilution, container limits and restart parity.

- [Plates, tube boxes and stacks](layouts.md): permanent wells, aggregate moves
  and disposal, ordered retrieval and refusal.

- [Composition and concentrations](concentration.md): exact ratios, explicit
  unknowns, lossless edits and immutable input facts.

- [Reservations](reservations.md): explicit holds, available quantity, partial
  fulfillment, stable holders and recorded release or expiry.

- [Physical custody](custody.md): empty containers, aggregate checkout, return,
  missing observations, transit and immutable location history.

- [Physical configuration](physical-configuration.md): reusable types, pinned
  recipes, scoped fit evidence and source-backed installed arrangements.
