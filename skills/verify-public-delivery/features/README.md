# Public delivery features

| Feature | Observable result |
| --- | --- |
| [Development admission](admission.md) | Read-only preparation preserves holds; delivery readies a completed draft, queues its exact head once and verifies its merge. |
| [Preflight](preflight.md) | Ready development PRs and queue candidates pass affected syntax, type and desktop checks. |
| [Qualification](qualification.md) | Broad CI retains complete reports for its selected source after development merges and before promotion. |
| [Promotion](promotion.md) | An exact upstream source passes broad qualification before a history-preserving staging or production merge. |
| [Retained results](retained-results.md) | Each merged commit keeps its own completed CI results and original failure evidence. |
| [Native journeys](native-journeys.md) | The real desktop workflow retains source-bound observations and original captures. |
